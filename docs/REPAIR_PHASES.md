# 系统可信性修复分期

## 阶段 1：资讯成为决策证据（本分支已完成）

- 资讯严格过滤到 `information_cutoff`，未知发布时间与未来资讯不得参与预测。
- 跨来源标题归一化去重；记录官方、新闻、公告三类覆盖率。
- DeepSeek 输出有界市场/行业/个股影响、影响期限、置信度和操盘行为信号。
- LLM 输出经过 ID、数值范围、股票代码和行为枚举校验；结果按文档与模型版本缓存。
- 词典基线作为可解释兜底，但默认要求 LLM 影响评估成功才允许生成主推荐。
- 资讯证据进入市场状态、次日情景、板块排序和个股排序，不再只是报告附件。
- 操盘行为输出包含支持、反证与次日验证条件；没有证据时不作确定性表述。
- 每次运行保存独立 `evidence_snapshot`，为后续训练历史资讯因子积累 PIT 样本。

## 阶段 2：线上正确性与降级（本分支已完成）

- 修复倒序日期导致规则层只读一天数据的问题。
- 修复涨跌停重复计数、新高新低按股票行 `tail` 的轴错误、波动率百分比单位错误。
- 落实流通市值、PE、上市 60 天、20 日成交额、市场范围和有限值硬过滤。
- 资讯不足进入 `facts_only`，行情不足进入 `abstain`，二者均取消主推荐。
- 旧市场/板块/个股模型默认不再覆盖规则，只有明确通过新基线和成本门槛的产物才启用。
- 正式报告按目标日防重；研究/干跑预测不进入正式结果跟踪。
- JSON 中的 NaN/Infinity 统一转为 null。

## 阶段 3：训练、回测与模型晋级（本分支已完成）

- train / early-stop / calibration / validation 按完整交易日四段切分。
- Isotonic 校准和最终评价不再使用同一数据段。
- 个股与板块使用每日横截面 RankIC 均值，不再使用全样本 pooled IC 作为主指标。
- 回测股票池按每个历史日期分别执行市值、PE、成交额和上市天数门槛。
- 回测收益改为次日开盘到收盘代理收益，按实际持仓变化计算换手和单边 bp 成本，
  净值与回撤使用复合计算。
- 市场模型必须跑赢无条件 Brier 基线；板块/个股必须跑赢动量每日 IC 基线。
- 模型产物临时目录写完后原子发布；最新产物损坏时自动回退上一完整版本。

## 阶段 4：仍需积累数据后完成

- 资讯影响模型目前通过有界证据融合进入线上推断；需要积累足够的
  `evidence_snapshot + outcome` 后，才能把新闻/政策特征纳入监督模型并做真正样本外训练。
- 历史 ST 名称和历史行业变更仍缺少完整 PIT 数据源；当前已纳入退市股票与历史上市日期，
  但行业历史只能标记为部分 PIT，不能宣称完全无幸存者偏差。
- 当前可执行收益使用“次日开盘到收盘”代理；15 分钟确认条件必须接入分钟档案后才能
  回放是否成交、成交价和取消条件。
- 需要至少 60 个正式交易日再评价资讯增量：比较“价量模型”和“价量+资讯证据”的
  Brier、每日 IC、Top-K 成本后收益与弃权覆盖率。

## 发布验收顺序

1. 在隔离目录运行全部测试和 compileall。
2. 对生产数据库只读回放，确认窗口日期数、硬门槛和资讯截止过滤。
3. 部署代码但保留 `--no-push`，执行一次目标日干跑。
4. 核查报告中的证据、反证、系统状态、模型组件批准状态和无 NaN。
5. 只有 `system_status=normal` 且企业微信链接可访问时恢复正式推送。
